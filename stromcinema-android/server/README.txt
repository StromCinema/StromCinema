Strøm server (slim, no torrents)

1. Install Node.js if you don't have it.
2. Double-click start-server.bat (first run installs packages, then starts).
   Or in a terminal: npm install, then: node strom-server.cjs
3. Open http://localhost:5000/setup, add movie folders + TMDB key, Save.
   (A plexus-config.json in this folder is used automatically.)
4. The console shows the TV address, e.g. 192.168.1.20:5000
